# Description 规则与高风险修复

日期：2026-09-30。此文件记录首次扫描之后的实现变更。

## 新规则

在第一张工作表中精确识别 `DescOfMerchandish` 和 `Description`，忽略列名大小写和两端空格。适用于 SHEIN、Boohoo Pure、Boohoo Hybrid。

每个值依次执行：

1. 转文本并做 Unicode NFC 规范化。
2. 删除标点、符号和 emoji；保留文字、组合标记、数字和空白。
3. 将连续空白（包括换行、TAB）缩成一个普通空格，并去除首尾空白。
4. 取前 75 个 Unicode 码点，写回原单元格，单元格类型为文本。

例如 `  Men's / cotton   shirt! 👕  ` → `Mens cotton shirt`。缺少某一列时处理存在的列；不会创建缺失列或修改其他名称含 description 的列。清理直接进入 ZIP 中的结果 Excel，MID 汇总 CSV 仍仅记录 MID 变更。
